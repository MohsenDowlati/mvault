# mVault

mVault is a blazing-fast, privacy-first desktop password manager written in Rust. Powered by a self-contained SQLite backend, it offers a clean, intuitive interface to securely store and organize account credentials for every service you use—completely offline, zero bloat, and entirely under your own ownership.

# Build

Clone the repository and build the project:
```rust
cargo build --release
```
The binary will be available at:
```rust
target/release/mvault
```
